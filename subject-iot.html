MTCSE1107

Internet of Things

IoT Architectures, Protocols, Embedded Design, Analytics & Case Studies

5 Units Elective 3 Credits

Course Objectives

  • Understand smart objects and IoT architectures.
  • Learn about various IoT-related protocols.
  • Build simple IoT systems using Arduino and Raspberry Pi.
  • Understand data analytics and cloud in the context of IoT.
  • Develop IoT infrastructure for popular applications.

Course Outcomes

After completing this course, a student will be able to:

  • Summarise the term 'internet of things' in different contexts.
  • Analyse various protocols for IoT.
  • Design a proof-of-concept of an IoT system using Raspberry Pi/Arduino.
  • Apply data analytics and use cloud offerings related to IoT.
  • Analyse applications of IoT in real-time scenarios.
