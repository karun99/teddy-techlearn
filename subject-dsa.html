MTCSE1102

Advanced Data Structures & Algorithms

Linked Lists, Stacks, Queues, Searching, Sorting, Trees, Graphs, Heaps & Search Trees

5 Units Core 3 Credits

Course Objectives

  • Learn single and doubly linked lists, stacks, queues, searching and sorting, trees, binary trees and their traversals, and graphs - storage and traversal.
  • Study dictionaries, ADTs for List, Stack, Queue, Hash table representation, Hash functions and Priority queues using heaps.
  • Study AVL, Red-Black and Splay search trees and compare search trees.

Course Outcomes

After completing this course, a student will be able to:

  • Write and analyse algorithms for correctness and efficiency.
  • Master a variety of advanced abstract data types and data structures and their implementation.
  • Apply searching, sorting and hash techniques to solve real-life problems.
  • Design and implement data structures including linked lists, binary trees, heaps, graphs and search trees.
  • Compare various search trees and find solutions for IT-related problems.
