MTCSE1206

MEAN Stack Technologies Lab

HTML, JS, PHP, Angular, React & MongoDB experiments

5 Units Lab 2 Credits

Course Objectives

  • Learn the core concepts of frontend and backend programming.
  • Get familiar with the latest web development technologies and SQL and Mongo databases.

Course Outcomes

After completing this course, a student will be able to:

  • Identify basic web and markup concepts and develop web applications using scripting and frameworks.
  • Create and run applications using JSP, AngularJS and React JS.
