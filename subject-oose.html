MTCSE1108

Object Oriented Software Engineering

Software Processes, OO Analysis, Design, Testing, Metrics & CASE Tools

5 Units Elective 3 Credits

Course Objectives

  • Elicit, analyse and specify software requirements through a productive working relationship with stakeholders.
  • Understand the software life cycle, how software projects are planned and managed, and how risks are identified and assessed.
  • Identify, formulate and solve software engineering problems including specification, design, implementation and testing.

Course Outcomes

After completing this course, a student will be able to:

  • Apply the object-oriented software-development process to design software.
  • Analyse and specify software requirements through an SRS document.
  • Design and plan software solutions to problems using an object-oriented strategy.
  • Model object-oriented software systems using the Unified Modeling Language (UML).
  • Estimate the cost of constructing object-oriented software.
