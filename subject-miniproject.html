MTCSE1207

Mini Project with Seminar

Independent mini project with seminar presentation

5 Units Mini Project 2 Credits

Course Objectives

  • Develop the ability to define and deliver a small-scale technical project.
  • Present technical work and defend it in a seminar.

Course Outcomes

After completing this course, a student will be able to:

  • Apply software/tools to build a working mini project.
  • Communicate project outcomes effectively in a seminar.
