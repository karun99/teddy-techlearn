MTCSE1202

MEAN Stack Technologies

Web, JavaScript, Node.js, Express, REST, React & MongoDB

5 Units Core 3 Credits

Course Objectives

  • Translate user requirements into the overall architecture and implementation of new systems.
  • Write optimised front-end code in HTML and JavaScript.
  • Monitor performance of web applications and troubleshoot.
  • Design and implement robust and scalable front-end applications.

Course Outcomes

After completing this course, a student will be able to:

  • Identify the basic concepts of web and markup languages.
  • Develop web applications using scripting languages and frameworks.
  • Make use of Express.js and Node.js frameworks.
  • Illustrate the use of web services concepts like RESTful and React.js.
  • Adapt to deployment techniques and working with cloud platforms.
