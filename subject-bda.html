MTCSE1103

Big Data Analytics

Hadoop, NoSQL, Cassandra, MapReduce, Hive & Spark

5 Units Elective 3 Credits

Course Objectives

  • Provide an overview of the exciting growing field of big data analytics.
  • Introduce the tools required to manage and analyse big data like Hadoop, NoSQL, Map Reduce, Hive, Cassandra and Spark.
  • Teach fundamental techniques and principles of big data analytics with scalability and streaming capability.
  • Optimise business decisions and create competitive advantage with big data analytics.

Course Outcomes

After completing this course, a student will be able to:

  • Illustrate big data and its use cases from selected business domains.
  • Interpret and summarise NoSQL and Cassandra.
  • Analyse Hadoop and Map Reduce technologies and explore Big Data applications using Hive.
  • Make use of Apache Spark and RDDs to work with datasets.
  • Assess real-time processing with Spark Streaming.
