MTCSE1104

Digital Image Processing

Image Fundamentals, Enhancement, Filtering, Compression, Wavelets, Segmentation & Watermarking

5 Units Elective 3 Credits

Course Objectives

  • Describe and explain the basic principles of digital image processing.
  • Design and implement algorithms for basic image processing like noise removal and image enhancement.
  • Design and implement algorithms for advanced image analysis like image compression and image segmentation.
  • Assess the performance of image processing algorithms and systems.

Course Outcomes

After completing this course, a student will be able to:

  • Demonstrate the components of image processing.
  • Explain various filtration techniques.
  • Apply image compression techniques.
  • Discuss the concepts of wavelet transforms.
  • Analyse the concept of morphological image processing.
