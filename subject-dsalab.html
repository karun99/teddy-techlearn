MTCSE1106

Advanced Data Structures & Algorithms Lab

Hands-on Java experiments on data structures

5 Units Lab 2 Credits

Course Objectives

  • Know about OOPs concepts for a specific problem.
  • Implement various advanced data structure concepts like arrays, stacks, queues, linked lists, graphs and trees.

Course Outcomes

After completing this course, a student will be able to:

  • Identify classes, objects, members of a class and relationships for a specific problem.
  • Examine algorithm performance using prior analysis and asymptotic notations.
  • Apply advanced data structures to solve complex problems.
  • Apply and analyse the functions of a dictionary.
